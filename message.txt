1. PROJECT GOAL
--------------------------------------------------------------------------------

Build a risk-scoring system for American Airlines crew sequences at DFW hub.

A "sequence" is a tail-matched aircraft rotation:
  - Crew flies A → DFW (inbound leg)
  - Same aircraft, same crew: DFW → B (outbound leg)
  - Turnaround window: 30–240 minutes at DFW

Predict: probability that this rotation experiences weather disruption.

Disruption = 1 if:
  - Weather delay >= 15 min on either leg, OR
  - Cascade: inbound late → late-aircraft departure on outbound (same tail)

Deliverables:
  1. XGBoost classifier with isotonic calibration
  2. Streamlit dashboard (HuggingFace Spaces)
  3. Hungarian algorithm sequence optimizer

HuggingFace Space: itaykadosh/AA-EPPS-Data-Challenge
GitHub (primary):  https://github.com/Optimax14/AA-EPPS-Data-Challenge
GitHub (fork):     https://github.com/22Ujjwal/Airline_Crew_Sequence

6. MODEL ARCHITECTURE
--------------------------------------------------------------------------------

PRIMARY MODEL: XGBoost v7 (current) / v8 (pending retrain)

  Val AUC:         0.825
  Val AP:          0.445
  Positive rate:   11.45%
  Training rows:   398,098
  Val split:       Time-based (train < 2024, val = 2024)
  Features:        70 across 8 groups

FEATURE GROUPS (70 total):

  Origin BTS (8):   weather_delay_rate, cancel_rate, avg/p75/p95 delay, NAS rate
  Dest BTS (8):     same for airport B
  Pair BTS (6):     combined/max/min/sum weather rate, avg delay, both_high_risk
  Temporal (6):     Month, is_spring_summer, median_turnaround_min, season dummies
  Origin GSOM (5):  avg_wind_speed, precip_days, extreme_precip, total_precip, max_wind_gust
  Dest GSOM (5):    same for airport B
  Pair GSOM (5):    pair_max_* for each GSOM feature
  DFW Hub (4):      DFW_weather_delay_rate, cancel_rate, avg/p95 delay_min
  Tail-Chain (13):  legs_before, block_before, duty_start_hour, total_duty, fdp_util,
                    fdp_overrun, wocl_rate, legs_after, legs_in_day, downstream_rate,
                    cascade_late_rate/min/amplif
  Airport Cascade (6): A/B ap_cascade_rate, ap_cascade_given_late, pair_cascade_product/max
  Multi-Hop (8):    n_hops, total_late_min, cascade_hop_rate, cascade_depth,
                    unique_airports, recovery_rate
  Interaction (3):  A_B_weather_coincidence, B_given_A_risk_ratio, pair_max_weather_rate

LABELING:
  target = 1 if observed_bad_rate > 0.25
  scale_pos_weight = 7.73 (class imbalance)
  observed_bad_rate = fraction of tail-matched rotations with weather delay >= 15 min
                      OR cascade (inbound late → late-aircraft outbound)

CALIBRATION:
  Raw XGBoost log-odds → isotonic regression → observed bad rate scale
  309 breakpoints in calibration_isotonic.json
  Example: MCO→LAX June: calibrated 9.7%, observed 11.6%

ALTERNATE: LightGBM v5
  NOT yet rebuilt on tail-matched data (uses old corridor-day dataset, inflated AUC).
  Retrain using src/model_lgbm.py after XGBoost v8 is done.

8. ML STRATEGY (designed this session)
--------------------------------------------------------------------------------

PROBLEM FRAMING:
  - Binary classification (NOT regression) — calibrated probability output
  - Target: observed_bad_rate > 0.25 threshold (absolute, not median-split)
  - Dual-head option for future: Head 1 binary (AUC/AP), Head 2 regression on
    observed_bad_rate (for optimizer ranking)

DATA STRATEGY:
  - Global model across all airports (NOT per-airport — too few sequences per pair)
  - Airport clustering (KMeans k=5) as FEATURE, not model split
  - Clusters: hub-congested, weather-dominated, small-regional, sun-belt, coastal-convective
  - Time split: train 2015–2022, val 2023, test 2024 (NEVER random CV)

VALIDATION:
  - Rolling window CV for hyperparameter tuning:
      Fold 1: train 2015–2020, val 2021
      Fold 2: train 2015–2021, val 2022
      Fold 3: train 2015–2022, val 2023
  - Metrics in priority order: AP > AUC > Calibration ECE > Top-decile lift > Brier

MODEL STACK:
  Tier 1: XGBoost v8 (retrain with new features) — target AUC 0.835
  Tier 2: LightGBM rebuilt on tail-matched data  — target AUC ~0.83
  Tier 3: Ensemble blend 0.55*XGB + 0.45*LGBM   — target AUC 0.845

LEAKAGE RISKS (do NOT use these as features):
  - observed_bad_rate (it IS the target)
  - n_sequences for current month (known only after month ends)
  - avg_risk_score / max_risk_score (model output — circular)
  - Same-month BTS delay stats computed on current month
  - prev_month_bad_rate without proper shift(1) grouped by (airport_A, airport_B)

9. FEATURE ENGINEERING — PRIORITIZED LIST
--------------------------------------------------------------------------------

MVP 15 FEATURES (get to AUC ~0.80 with these alone):

  # Weather (5)
  A_precip_days               Days precip > 0.1 in at origin
  A_max_gust_mph              Monthly max wind gust (from openmeteo)
  DFW_weather_delay_rate      Hub shared risk — all sequences pass DFW
  pair_max_precip_days        max(A_precip_days, B_precip_days)
  A_severe_wx_days            Days total precip > 4 in (heavy event proxy)

  # Temporal (3)
  prev_month_bad_rate         Storm clustering — bad months follow bad months
  same_month_prior_year_bad_rate  Seasonal memory
  is_peak_season              Month in {6,7,8,12}

  # Network (4)
  A_ap_cascade_rate           Airport propagation history
  tc_cascade_late_rate        Tail-level cascade rate
  mhc_cascade_hop_rate        Network reach of disruption
  pair_cascade_product        A_ap_cascade_rate × B_ap_cascade_rate

  # Ops (2)
  median_turnaround_min       Ground time buffer — key recovery signal
  tc_fdp_util_mean            Crew FDP utilization ratio

  # Static (1)
  A_weather_delay_rate        Historical baseline disruption rate

HIGH-VALUE ADDITIONS FOR V2:

  A_precip_intensity          total_precip / (precip_days + 1) — heavy vs drizzle
  B_precip_intensity          Same for airport B
  A_thermal_spread            avg_temp_max - avg_temp_min — convective instability
  A_extreme_cold_days         Days min temp < 32°F — de-ice queue risk
  A_extreme_heat_days         Days max temp > 95°F — weight restrictions
  pair_wx_coincidence         A_precip_days × B_precip_days
  month_sin / month_cos       sin/cos(2π×month/12) — cyclical encoding
  tc_fdp_overrun_rate         Fraction where FDP exceeds legal limit
  tc_wocl_rate                Night ops crossing 0200–0559 local
  mhc_total_late_min_mean     Total accumulated late minutes across chain
  A_hub_centrality            PageRank on delay-weighted airport graph
  A_cluster_id                KMeans cluster (one-hot, k=5)

13. COMMON GOTCHAS
--------------------------------------------------------------------------------

  1. Pandas suffix collision in merge: pre-rename flight-specific columns before
     merging to avoid silent column name mangling.

  2. XGBoost feature name mismatch: adding/removing FEATURE_COLS without retraining
     causes ValueError at inference. Always retrain after changing FEATURE_COLS.

  3. OOM on predict_proba: score in batches of 50k rows, not all 398k at once.

  4. Season dummy capitalization: pd.get_dummies produces season_Fall (capital).
     Model trained with lowercase season_fall. Don't change casing without retraining.

  5. app_features_cache.parquet: delete after any processed parquet update.
     Stale cache causes app to silently use old data.

  6. COVID years 2020–2021: available via --include-covid flag but excluded from
     training by default (abnormal operations distort the model).

  7. thunder_days: all zeros in openmeteo cache. ERA5 daily doesn't capture
     sub-daily convection. Skip this feature entirely.

  8. fit_calibration.py: NOT in repo. Lives at /tmp/ on training machine.
     Must be run after every model retrain.

  9. pair_max_weather_rate: was missing from sequence_features.parquet.
     Now computed in load_features() in src/model.py. Fixed this session.

  10. conda pip broken on local Mac: use python3 directly, not pip command.
